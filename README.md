# ezGame

마인크래프트 베드락 미니게임 서버 **EZ**를 혼자 만들고 운영하면서 남기는 기록이다.
접속 주소는 `ezgame.kr` (포트 19132), 정식 오픈은 2026년 11월 20일이다.

게임 소스 전체는 비공개로 두고, 여기에는 남들에게도 쓸모 있을 만한 것만 골라 올린다.
운영하다 막혔던 문제를 어떻게 찾고 고쳤는지, 그리고 서버 엔진에 직접 붙인 패치들이다.

## 서버 구성

- 엔진: [Axolotl-PM](https://github.com/axolotl-pm/PocketMine-MP) 5.51.2 (PocketMine-MP 포크, PHP 8.4)
- 플러그인: 직접 만든 PHP 플러그인 10개. 공통 기능(로비, 경제, 메뉴, 운영 도구)을 맡는 `EZCore`에 게임마다 하나씩 붙는다
- 게임: 재난의 섬, 컬러 러시, 젤리 미로, 바이러스, 미믹, 은행 털이, 보물 찾기 등
- 서버: 공유형 2코어 · 램 2GB VPS 한 대 (월 13,100원). 원래 4GB였는데 오픈 전에 반으로 줄였다
- 리소스 팩: UI, 모델, 음악을 전부 코드로 만든다. 그림을 손으로 그린 건 거의 없다

## 라이선스

엔진 패치(`engine/patches/`)는 엔진과 같은 LGPL-3.0을 따른다.
글과 그 밖의 파일은 따로 적지 않는 한 저작권을 가진다. 인용은 출처만 밝히면 괜찮다.

마인크래프트는 Mojang의 상표이고, EZ는 공식 마인크래프트 서비스가 아니다.
